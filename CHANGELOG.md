# Histórico de versões

## 1.0.2 — 17/10/2026

- Mantido Nuxt 4.6.2, sem rebaixamento inseguro sugerido pelo `npm audit fix --force`.
- Dependências do framework movidas para `devDependencies`, pois o deploy é estático.
- Atualizado `vue-tsc` para a série compatível com Nuxt 4.
- Removidas declarações redundantes de Vue e Vue Router para respeitar as versões exigidas pelo Nuxt.
- Servidor local de desenvolvimento restrito a `127.0.0.1`.
- Documentadas as vulnerabilidades transitivas ainda sem patch upstream.

## 1.0.1 — 17/10/2026

- Migração para Nuxt 4.6.2 após auditoria apontar vulnerabilidades altas na árvore Nuxt 3.
- Estrutura atualizada para `app/` e dependências revalidadas.

## 1.0.0 — 17/10/2026

- Estrutura institucional completa para o Estúdio Dobra.
- Nuxt, Vue 3 e TypeScript com geração estática.
- Estudos conceituais residenciais e comerciais com imagens WebP locais.
- Identidade vetorial SVG e PNG transparente.
- Formulário demonstrativo com encaminhamento para WhatsApp.
- Arquivo de publicação Netlify configurado.
